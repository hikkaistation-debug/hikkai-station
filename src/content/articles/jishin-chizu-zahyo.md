## ポイント

- 地震のあとの筆界の考え方は、**その場所で地面がどう動いたか**で変わります。「熊本地震ならこう、能登半島地震ならこう」と、地震ごとに決まるものではありません。
- 地震による**地殻変動で、広い範囲の地面が水平に動いた**場合は、筆界も一緒に動いたものとして扱われます（平成7年の法務省民事局長回答）。
- **崖崩れなどの局部的な土砂の移動**や、**液状化による側方流動**では、筆界は動かないものとして扱われます。
- 筆界が動いたと扱う地域では、地図の座標を直す作業が、筆界が動かないと扱う地域では、今の土地の形に合わせる分筆などの手続きが話題になります。

## 1つの地震でも、地面の動き方は場所によってちがう

熊本地震（2016年）について、国土交通省は「震源近辺においては、特に複雑な地殻変動が発生し」たと説明しています。

能登半島地震（2024年）では、能登半島を中心に大きな地殻変動が観測され、国土地理院は2024年1月5日に、その地域と周辺の基準点の測量成果の公表を止めました。対象には石川県の七尾市・輪島市・珠洲市のほか、羽咋市・かほく市・内灘町なども含まれていました（国土交通省の2024年1月10日の事務連絡）。

一方、同じ能登半島地震で、金沢市・羽咋市・かほく市・内灘町では、液状化にともなって地盤が水平方向に動く「側方流動」が起き、土地の境界と今の土地の形にずれが生じました。

このように、1つの地震の中にも、いろいろな動き方が混じっています。

## 動き方による筆界の考え方

| 地面の動き方 | 筆界の扱い | もとになっているもの |
| --- | --- | --- |
| 地殻変動で、広い範囲の地面が水平に動いた | 筆界も**相対的に移動した**ものとして扱う | 平成7年3月29日 民三第2589号 民事局長回答（兵庫県南部地震による土地の水平地殻変動と登記の取扱いについて） |
| 崖崩れなど、局部的に土砂が動いた | 筆界は**移動しない**ものとして扱う | 同じ回答 |
| 液状化による側方流動で動いた | 地殻変動をともなうものではないため、原則どおり、筆界は**移動していない**ものとして扱う | 能登半島地震について、法務省がプロジェクトチームで示した考え方（2025年） |

法務省は、平成7年の回答について、筆界はもともと動かないものだが、**地殻変動があった場合に限って例外的に動く**とした点に意味があり、地表面の局部的な移動は、**規模が大きくても**原則どおり筆界は動かない、と説明しています。

側方流動でも筆界が動いたと扱うことについては、ずれのしわ寄せを受けた土地の所有者が、所有権の一部または全部を、補償なく失うおそれがあることなどから、慎重な検討が必要としています。

## 筆界が動いたと扱う地域では：地図の座標を直す

筆界が地面と一緒に動いたと扱うと、地震の前に作られた地図や地積測量図に書かれた座標の値は、今の位置とずれることになります。地積測量図には、筆界点の座標値が記録されています（不動産登記規則77条1項8号）。

| | 熊本地震 | 能登半島地震 |
| --- | --- | --- |
| 地図の座標 | 法務省は、登記所の地図や地積測量図などの筆界点の座標値が、現在の座標値と異なる可能性があると案内。地図証明書などに「地震以前の情報による」旨を注記し、座標値の補正作業をした登記所では注記を削除 | 国土地理院が基準点の成果の公表を止めた（2024年1月5日）。作業中の地籍調査は、地震の前に観測した結果が必ずしも使えないため、次の工程に進めない暫定的な扱いになった（国土交通省の事務連絡） |
| 直すための取り組み | 国土交通省が震源近辺の967か所で測量し、地殻変動量から、地籍図などを計算で直せる補正パラメータを公開（2017年3月30日） | — |

熊本地震の案内で、法務省は、地図証明書や図面証明書を取った人に、地図などの**作成年月日を確かめて扱うよう**呼びかけています。地震の前に作られた図面の座標を使うときは、いつの時点の値なのかを意識することが大切です。

## 筆界が動かないと扱う地域では：今の形に合わせる手続き

側方流動の地域では、筆界も、登記されている筆界の座標値も変わっていない、と扱われます。法務省は、登記されている座標値と、側方流動でずれた先とを比べることで、分筆・所有権移転をするべき範囲が明らかになる、と説明しています。

住民が今の形のまま使い続けることを望み、関係者のあいだで合意ができている場合などには、今の法律でも、次の方法で解決できるとされています。

| 方法 | 内容 |
| --- | --- |
| 分筆と所有権の移転 | ずれた部分を分筆し、その部分の所有権を、合意（売買・贈与など）にもとづいて、となりの土地の所有者に移す |
| 分筆のしかた | ①土地の所有者が申請する方法と、②地籍調査で「分割があったものとしての調査」をして、その成果にもとづき登記官が職権で行う方法がある。②なら測量費用や登記費用はかからない |
| 土地区画整理事業 | 換地処分によって、今の形に合わせた新しい筆界をつくる |

法務省は、北海道胆振東部地震の事例のように、分筆・所有権移転で対応することが考えられる、とも述べています。

### 能登半島地震の側方流動の地域での取り組み

国土交通省・法務省・石川県・被災市町（金沢市・羽咋市・かほく市・内灘町）などでつくる「能登半島地震に伴う土地境界問題対策プロジェクトチーム」が、2025年9月に「土地境界再確定加速化プラン」をまとめ、地籍調査を短い期間で集中して行う取り組みが進められています。2026年4月からは、全国の自治体からかほく市・内灘町に応援職員が派遣されています。

登記の費用については、租税特別措置法84条の5の2にもとづく特例が、2026年（令和8年）4月1日に施行された法律で設けられました。次のすべてにあてはまると、所有権の移転登記の登録免許税が免除されます。

| 要件 | 内容 |
| --- | --- |
| 場所 | 石川県金沢市・羽咋市・かほく市・河北郡内灘町で、側方流動の被害回復のために実施された地籍調査の調査地域 |
| ずれ | 地籍調査で調査された境界（実際の利用状況）が、登記所の地図の筆界とちがうことになった土地 |
| 分筆 | ずれを直すため、地籍調査で土地の分割があったものとして調査され、その成果にもとづいて分筆の登記がされた土地 |
| 取得 | 分筆後の土地に隣接する他の土地の登記名義人が、分筆後の土地の所有権を取得したこと |
| 期限 | 分筆の登記が完了してから1年以内に、所有権の移転の登記を申請すること |

申請書には、市長または町長の証明書をつけます。登記手続きの窓口は金沢地方法務局です。

## 複雑に動いたところは、話し合いから

地割れをはさんで、両側の土地が逆の方向に動いたような場所もあります。熊本地震のあとの報道で、日本土地家屋調査士会連合会の理事は「土地が複雑に移動したときの筆界について、実体法上決まったものはありません。そのためまずは土地の所有者など当事者間で調整を図ります」と説明しています。

弁護士の解説でも、1つの街区にゆがみが出たときに、それぞれが元の境界どおりと主張し続けると、最後にはとんでもない形の土地しか残らないことがあり、街区の中の土地が少しずつゆがみを吸収するかたちで調整する必要が出てくる、と述べられています。

## 自分の土地は、どれにあたる？

自分の土地で起きた動きが、広い範囲の地殻変動なのか、局部的な移動なのか、側方流動なのかで、考え方が変わります。1つの地震の中でも場所によってちがうため、専門的な判断が必要です。

ご自分の土地のことは、**法務局**や**土地家屋調査士会**にご相談ください。このサイトでは、個別のご相談はお受けしていません。
