## ポイント

- 大きな地震では、地面そのものが動くことがあります。
- 熊本地震では、登記所の地図などに書かれた**座標の値が、現在の値と異なる可能性**があると、法務省が案内しました。
- 能登半島地震では、液状化にともなう側方流動で、**地図の筆界と実際の土地の使われ方にずれ**が生じた地域について、登録免許税の特例が設けられました。

## 地面の動き方は、大きく2つ

| 動き方 | どんなものか |
| --- | --- |
| 地殻変動 | 地震で、広い範囲の地面がまとまって動く |
| 側方流動 | 液状化した地盤が、横に流れるように動く |

## 法務省の案内の比較

| | 熊本地震（2016年） | 能登半島地震（2024年） |
| --- | --- | --- |
| 話題 | 地殻変動と、地図などの座標値 | 側方流動と、筆界と利用状況のずれ |
| 影響 | 地図や地積測量図などの筆界点の座標値が、現在の座標値と異なる可能性がある | 法務局の地図に描かれた筆界と、実際の利用状況がずれた |
| 対応 | 地図証明書などに「地震以前の情報による」旨の注記。座標値の補正作業をした登記所では注記を削除 | ずれを解消する分筆登記と所有権移転登記について、登録免許税を免除する特例 |

## 地図や地積測量図を取るときの注意

熊本地震の案内で、法務省は、地図証明書や図面証明書を取った人に、地図などの**作成年月日を確かめて扱うよう**呼びかけています。

地積測量図には、筆界点の座標値が記録されています（不動産登記規則77条1項8号）。地震の前に作られた図面の座標を使うときは、いつの時点の値なのかを意識することが大切です。

## 能登半島地震の登録免許税の特例

租税特別措置法84条の5の2にもとづく特例で、2026年（令和8年）4月1日に施行された法律で設けられました。次のすべてにあてはまると、所有権の移転登記の登録免許税が免除されます。

| 要件 | 内容 |
| --- | --- |
| 場所 | 石川県金沢市・羽咋市・かほく市・河北郡内灘町で、側方流動の被害回復のために実施された地籍調査の調査地域 |
| ずれ | 地籍調査で調査された境界（実際の利用状況）が、登記所の地図の筆界とちがうことになった土地 |
| 分筆 | ずれを直すため、地籍調査で土地の分割があったものとして調査され、その成果にもとづいて分筆の登記がされた土地 |
| 取得 | 分筆後の土地に隣接する他の土地の登記名義人が、分筆後の土地の所有権を取得したこと |
| 期限 | 分筆の登記が完了してから1年以内に、所有権の移転の登記を申請すること |

申請書には、市長または町長の証明書をつけます。登記手続きの窓口は金沢地方法務局です。

## 筆界は動くの？

地震のあと筆界をどう考えるかは、地面の動き方や個別の事情によって、専門的な判断が必要になります。この記事では、法務省の上記の案内に書かれていることだけを紹介しています。

ご自分の土地のことは、**法務局**や**土地家屋調査士会**にご相談ください。このサイトでは、個別のご相談はお受けしていません。

熊本地震の案内は、法務省の「[平成28年熊本地震による地殻変動に伴う地図等証明書上の座標値表示への影響について](https://www.moj.go.jp/MINJI/minji05_00256.html)」で読めます。
