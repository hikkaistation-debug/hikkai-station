## どんな登記？

建物の所在・種類・構造・床面積などを、初めて登記簿に書く登記です。新築から**1か月以内**に申請する義務があります（不動産登記法第47条）。この登記で登記簿の「表題部」ができ、そのあとに所有権保存登記や、住宅ローンの抵当権設定登記ができるようになります。

流れは、[土地家屋調査士ってどんな人？](/articles/chousashi-towa/)の図でも説明しています。

## おもな必要書類

| 書類 | 内容 |
| --- | --- |
| 建物図面・各階平面図 | 土地家屋調査士が現地で測って作る |
| 所有権を証明する書類 | 建築確認済証・検査済証、工事をした会社の引渡証明書など |
| 住所を証明する書類 | 持ち主の住民票など |

## 床面積が建築確認とちがう理由

いちばん大きな理由は、**もとになる法律がちがう**ことです。

| | 登記の床面積 | 建築確認の床面積 |
| --- | --- | --- |
| もとになる法律 | 不動産登記法（不動産登記規則第115条など） | 建築基準法（建築基準法施行令第2条第1項第3号など） |
| 目的 | 建物がどんなものかを、登記簿で公に示す | 建物が安全か、建ててよい大きさかを確かめる |
| 基本の測り方 | 各階の、壁などの中心線で囲まれた部分（マンションの部屋などの区分建物は、壁の内側の線） | 各階の、壁などの中心線で囲まれた部分 |

基本の測り方はよく似ていますが、**どの部分を床面積に入れるか（算入するか）**の細かい決まりが、それぞれの法律の運用でちがいます。そのため、同じ建物でも数字がちがうことがあります。

| ちがいが出やすい部分 | 登記の床面積では |
| --- | --- |
| 区分建物（マンションの部屋など） | 壁の中心ではなく内側の線で測るので、パンフレットの面積（壁の中心）より小さくなる |
| ロフト・小屋裏収納 | 天井の高さなどによって、床面積に入らないことがある |
| 吹き抜け | 床がない部分なので入らない |
| バルコニー・ポーチ | 屋内として使える状態かどうかで、入らないことが多い |

※どの部分を入れるかは、建物の形や使い方によって判断がちがいます。くわしくは土地家屋調査士に相談しましょう。

## 費用

- 登録免許税：かからない
- 土地家屋調査士への報酬：建物の大きさや資料の有無で変わります
