## 合筆とは

となりあう「1番」と「2番」の土地を、1つの土地にまとめる登記です。土地の数が減るので、管理や将来の手続きがわかりやすくなります。合筆した土地の間にあった筆界は、なくなります。

## まとめられないケース（不動産登記法第41条）

<figure class="figure">
  <a href="/images/kiso/gappitsu-dekinai.svg" target="_blank" rel="noopener"><img src="/images/kiso/gappitsu-dekinai.svg" alt="合筆できない代表的な例。土地がつながっていない、地目がちがう、持ち主や持分がちがう、片方にだけ抵当権が付いている" width="640" height="300" loading="lazy" /></a>
  <figcaption>代表的な例です。くわしくは下の表を見てください。（図を押すと大きく表示します）</figcaption>
</figure>

| まとめられない場合 | 例 |
| --- | --- |
| 土地がつながっていない | 間に道路や他人の土地がある |
| 地目がちがう | 宅地と畑 |
| 地番区域（字など）がちがう | 「○○1丁目」と「○○2丁目」 |
| 持ち主がちがう | 1番はAさん、2番はBさん |
| 持ち主は同じでも持分がちがう | 1番はAさん・Bさん半分ずつ、2番はAさん3分の2・Bさん3分の1 |
| 所有権の登記がある土地とない土地 | 片方が表題部だけの土地 |
| 抵当権などの権利が登記されている | 片方にだけローンの抵当権が付いている（同じ抵当権がまとめて付いている場合などは、例外的にまとめられることがある） |

地目がちがうときは、先に地目変更の登記でそろえれば、まとめられることがあります。

## 費用

- 登録免許税：合筆後の土地1筆につき1,000円
- 手続きを頼む場合は、土地家屋調査士への報酬

合筆は、測量をしなくても申請できることが多い手続きです。まとめられるかどうか、まずは登記事項証明書で持ち主・地目・権利を確かめましょう。
