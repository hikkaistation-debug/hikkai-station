## どんなソフト？

エーサーベイ（A-Survey）は、測量の観測と計算を行うソフトです。開発や提供の体制は、公式サイトで確かめてください。現場では、Androidのスマートフォンやタブレットを、測量機器のコントローラー（操作と記録をする端末）のように使えます。

## 種類

| 名前 | 動く端末 | おもな使い道 |
| --- | --- | --- |
| A-SurveyAd | Android | 現場での観測と計算（いちばん新しく、更新が続いている） |
| A-SurveyPC | Windows のパソコン | 事務所での計算。Android版とデータをやりとりできる |
| A-SurveyCE など | Windows CE（昔の携帯端末） | 古い端末向け。今は更新が止まっている |

Android版には、機器とつないで観測できる版と、計算だけの版があります。

## できること（おもなもの）

| 分野 | 内容 |
| --- | --- |
| 機器とつなぐ | Bluetoothやケーブルでトータルステーション（トプコン・ニコン・ライカ・ペンタックスなど）とつないで観測。GNSS受信機（Droggerなど）とも連携 |
| 計算 | 座標計算、トラバース計算、杭打ち（測設）など。道路の計算・座標変換・面積の計算などはオプション |
| 図面・データ | DXFの読み込みと書き出し、SIMA形式の読み込み、LandXML（TIN）、CSV など |
| 記録 | 手書きメモや写真を、観測の記録に残せる |

※対応する機種や機能は、公式サイトの対応表と更新履歴で確かめてください。

## 料金と使い始め方

- **有料**のソフトです。本体のほかに、機能を足すオプションがあります。料金は公式サイトの登録ページで確かめてください。
- ライセンス（使う権利）は、スマートフォンの電話番号にひもづける方法と、専用のMicroSDカードにひもづける方法があります。MicroSDカードなら、別の端末に差し替えて使えます。
- 公式サイトにはデモ版の案内もあります。

## 選ぶときのポイント

| 確かめたいこと | 理由 |
| --- | --- |
| 自分の測量機器が対応しているか | 機種によって、通信の設定やつなぎ方がちがう |
| 使う端末が対応しているか | Androidのバージョンや機種で動作がちがうことがある（公式サイトに確認済みの端末の一覧あり） |
| 事務所のソフトとデータをやりとりできるか | SIMA・DXFなど、使うデータの形式を確かめる |

GNSSのしくみは、[GNSS測量とは？](/articles/gnss-towa/)で紹介しています。
