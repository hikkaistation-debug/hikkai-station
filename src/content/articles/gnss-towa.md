## GNSSとは ―― 機器ではなく「しくみ」の名前

GNSSは「Global Navigation Satellite System（全球測位衛星システム）」の頭文字です。人工衛星から届く電波を受けて、今いる位置を測るしくみをまとめてこう呼びます。

| 言葉 | 何のこと？ |
| --- | --- |
| GNSS | 衛星を使って位置を測る**しくみ**の総称（GPS・みちびきなど） |
| GNSS受信機（GNSS測量機） | 衛星の電波を受ける**機器**。測量では、三脚や棒の上につけて使う |
| GNSS測量 | GNSS受信機を使って、位置（座標）を測る**測量** |

「GNSSで測る」と言うときは、ふつう「GNSS受信機で衛星の電波を受けて測る」という意味です。

## おもな衛星

| 名前 | 国・地域 |
| --- | --- |
| GPS | アメリカ |
| みちびき（QZSS） | 日本 |
| GLONASS | ロシア |
| Galileo | ヨーロッパ（EU） |
| BeiDou | 中国 |

ふだん「GPS」と呼んでいるものも、今は複数の国の衛星を組み合わせて使うことが多くなっています。

## おもな測り方

| 測り方 | しくみ | 使われる場面 |
| --- | --- | --- |
| 単独測位 | 受信機1台で、衛星の電波だけを使って位置を出す | スマートフォン、カーナビ |
| 相対測位（スタティックなど） | 2台以上の受信機で同時に観測し、その差から位置を出す。同じ場所でしばらく観測を続ける | 基準点の測量 |
| RTK測位 | 位置のわかっている基準局と、測る点の受信機を通信でつなぎ、その場で位置を出す | 測量、工事、農業機械 |
| ネットワーク型RTK | 国土地理院の電子基準点などのデータから作った補正情報を使って、その場で位置を出す | 測量 |

## 精度は、測り方だけでは決まらない

どのくらい正確に測れるかは、測り方の名前だけでなく、次のようなことでも大きく変わります。

| 変わる理由 | たとえば |
| --- | --- |
| 空の見え方 | 建物・木・崖で衛星が隠れると、精度が落ちたり、測れなかったりする |
| 電波の反射 | 建物などに反射した電波を受けると、位置がずれる（マルチパス） |
| 観測の時間・回数 | 短い観測より、時間をかけたり何度か測ったりするほうが安定する |
| 基準局との距離・通信 | 基準局から遠い、通信が切れるなどで、精度が落ちることがある |
| 機器や設定 | 受信機の性能、アンテナの高さの入れ方など |

そのため、測量では、測り方を決めるだけでなく、測る場所の条件を見て、点検の観測をするなどして結果を確かめます。

## 測量ではどう使う？

- 土地の境目の位置を、**座標**（基準になる点からの位置の数字）で記録するときに使います。
- 国土地理院は、全国に約1,300か所の**電子基準点**を置いて、GNSSで位置を観測し続けています。
- 地震などで地面が動くと、座標もずれます。そのため、古い座標を使うときは注意が必要です。

## 気をつけたいこと

スマートフォンの地図アプリで見た位置には、数メートルのずれがあります。境目の位置を確かめる目的には使えません。
