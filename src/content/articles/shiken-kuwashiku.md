試験のおおまかな流れは、[土地家屋調査士試験のしくみ（はじめての方へ）](/articles/shiken-shikumi/)で紹介しています。この記事では、もう一歩くわしい中身をまとめます。

## 筆記試験の問題数と配点

| | 形式 | 問題数 | 満点 | 1問あたり |
| --- | --- | --- | --- | --- |
| 午前の部 | 多肢択一式（平面測量など） | 10問（第1〜10問） | 60点 | 6点 |
| 午前の部 | 記述式（作図） | 1問（第11問） | 40点 | ― |
| 午後の部 | 多肢択一式（民法・不動産登記法・土地家屋調査士法など） | 20問（第1〜20問） | 50点 | 2.5点 |
| 午後の部 | 記述式（土地・建物の書面と図面） | 2問（第21問 土地・第22問 建物） | 50点 | ― |

※問題数と満点は、令和7年度の試験問題と合格点の発表（法務省）による。

**午前の部**は、測量士・測量士補・一級建築士・二級建築士などの資格があれば免除されます。免除される人は、午後の部だけを受けます。

## 試験時間

| | 時間 | 長さ | 時間配分の目安 |
| --- | --- | --- | --- |
| 午前の部 | 9時30分〜11時30分 | 2時間（120分） | 択一10問と作図1問。作図に時間をとられやすい |
| 午後の部 | 13時00分〜15時30分 | 2時間30分（150分） | 択一20問と記述2問。記述（土地・建物）に多くの時間を残せるよう、択一を手早く解くのが大事 |
| 口述試験 | 受験票で指定 | 1人15分ほどの面接 | 筆記試験の合格者だけが受ける |

※試験時間は、予備校のサイト（[LEC](https://www.lec-jp.com/chousashi/about/shiken_chousashi.html)・[アガルート](https://www.agaroot.jp/chousashi/exam)）の案内による（2つのサイトで同じ時間）。開始の少し前に「着席」と「指定時刻」があり、指定時刻に遅れると受験できません。正式な時刻は、その年の受験案内書と受験票で確かめてください。「時間配分の目安」は、このサイトからの一般的なアドバイスです。

## 合格点（令和7年度の例）

合格するには、**合計点**と、それぞれの**基準点（足切り）**の両方をこえる必要があります。

| | 合計の合格点 | 多肢択一式の基準点 | 記述式の基準点 |
| --- | --- | --- | --- |
| 午前の部 | 100点中70.0点以上 | 60点中30.0点 | 40点中32.0点 |
| 午後の部 | 100点中76.0点以上 | 50点中37.5点 | 50点中32.5点 |

基準点に1つでも届かないと、合計点が高くても不合格です。合格点は毎年変わります。

| 項目 | 数 |
| --- | --- |
| 筆記試験 | 2025年10月19日 |
| 口述試験 | 2026年1月22日 |
| 受験者数 | 4,824人 |
| 合格者数 | 489人（男性430人・女性59人） |
| 合格率（合格者数÷受験者数） | 約10.1% |

## 1年の流れ（例年）

| 時期 | できごと |
| --- | --- |
| 7月上旬 | 受験申請書・受験案内書の配布が始まる（法務局の窓口・郵送。受験案内書は法務省のサイトでも公開） |
| 7月下旬〜8月上旬 | 受験申請の受付 |
| 10月（第3日曜日ごろ） | 筆記試験 |
| 翌年1月 | 筆記試験の合格者が、口述試験を受ける |
| 翌年2月ごろ | 最終合格の発表 |

令和8年度は、筆記試験が2026年10月18日、口述試験が2027年1月21日の予定です（[アガルートの日程表](https://www.agaroot.jp/chousashi/exam)より）。試験日や申請の期間は、その年の受験案内書で必ず確かめてください。

## 当日のルール（よくある疑問）

| 持ち物・ふるまい | ルール |
| --- | --- |
| 電卓 | 一定の条件の電卓だけ使える（予備を含めて2台まで）。プログラム機能・プリント機能・文字入力のあるもの、電池式以外のものは使えない。使える機種の例は法務省の「電卓の使用について」で公開されている |
| マークシート | 鉛筆（BかHB）で書く。シャープペンシルは問題用紙のメモだけ |
| 時計 | 会場に時計がないこともあるので、腕時計を持っていく。**スマートウォッチは使えない** |
| 下敷き | 使えない（必要なら板目紙を貸してもらえる） |
| 飲み物 | キャップ付きのペットボトル1本だけ机に置ける。水筒は置けない |
| 忘れ物 | 電卓・筆記用具・腕時計の貸し出しはない |

※法務省「よくあるお問合せ」「筆記試験における電卓の使用について」（令和8年度）より。
