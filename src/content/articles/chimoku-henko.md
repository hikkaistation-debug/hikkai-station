## 地目は23種類（不動産登記規則第99条）

| よく見る地目 | どんな土地？ |
| --- | --- |
| 宅地 | 建物の敷地と、その維持に必要な土地 |
| 田 | 水を利用して耕作する土地 |
| 畑 | 水を利用しないで耕作する土地 |
| 山林 | 竹木が生えている土地 |
| 原野 | 雑草や低木などが生えている土地 |
| 雑種地 | ほかのどれにも当てはまらない土地（駐車場・資材置き場など） |
| 公衆用道路 | 一般の人が通る道路 |

ほかに、学校用地・鉄道用地・塩田・鉱泉地・池沼・牧場・墓地・境内地・運河用地・水道用地・用悪水路・ため池・堤・井溝・保安林・公園があります。

## 地目は「今の使い方」で決まる

地目は、土地の今の使い方（現況）で判断されます。たとえば、登記簿は「畑」でも、家が建っていれば実際は「宅地」です。こうしたずれがあるときは、地目変更の登記をします。

## 地目変更登記

| 項目 | 内容 |
| --- | --- |
| いつまでに？ | 地目が変わった日から1か月以内（不動産登記法第37条） |
| だれが？ | 土地の持ち主（土地家屋調査士に頼むこともできる） |
| 登録免許税 | かからない |
| 注意 | 田・畑から変えるときは、先に**農地法の許可や届出**が必要 |

固定資産税の地目（課税地目）は、登記の地目とは別に決められるので、一致しないこともあります。
