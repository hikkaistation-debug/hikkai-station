## どんなときに分筆する？

| こんなとき | 例 |
| --- | --- |
| 相続で分けたい | 1つの土地を、兄と妹で半分ずつ持ちたい |
| 一部だけ売りたい | 土地の端の部分を、隣の人に売る |
| 使い道がちがう部分を分けたい | 宅地と畑が1つの土地になっている |
| 道路用地として提供する | 市の道路を広げるため、一部を市に渡す |

「1番」の土地を2つに分けると、ふつうは「1番1」と「1番2」になります。分けた土地の間には、**新しい筆界**ができます。

図での説明は、[「筆界」と「所有権の境」はちがうもの？](/articles/hikkai-to-shoyukenkai/)を見てください。

## 流れ

<figure class="figure">
  <a href="/images/kiso/bunpitsu-nagare.svg" target="_blank" rel="noopener"><img src="/images/kiso/bunpitsu-nagare.svg" alt="分筆登記の流れ。1 土地家屋調査士に相談、2 境界確定測量、3 分ける線を決めて境界標、4 地積測量図を作って申請、5 登記完了で新しい地番。名義を変えるなら司法書士へ" width="640" height="250" loading="lazy" /></a>
  <figcaption>まず今の境目を確かめてから、分ける線を決めます。（図を押すと大きく表示します）</figcaption>
</figure>

1. 土地家屋調査士に相談・依頼する
2. 境界確定測量（お隣・役所と境目を確認し、境界標を入れる）
3. 分ける線を決めて、新しい境目にも境界標を入れる
4. 地積測量図を作り、法務局に分筆登記を申請する
5. 登記が終わる（新しい地番が付く）
6. 名義を変える場合は、司法書士が所有権移転の登記をする

## 費用の内訳

| 費用 | 内容 |
| --- | --- |
| 測量・調査の報酬 | 境界確定測量と分筆登記の手続き。土地の広さ・お隣の数などで大きく変わる |
| 登録免許税 | 分筆後の土地1筆につき1,000円 |
| 実費 | 資料の取得費、境界標の代金など |

測量・調査の報酬は事務所によってちがうので、見積もりで確かめましょう。
