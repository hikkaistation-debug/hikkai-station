## GISとは

GISは「Geographic Information System（地理情報システム）」の頭文字です。**位置の情報（緯度・経度や座標）をもつデータ**を、地図の上に重ねて表示したり、調べたりするしくみのことです。

## 「重ねる」とはこういうこと

| 重ねるもの（レイヤー） | たとえば |
| --- | --- |
| 地図の土台 | 地形図、道路地図 |
| 写真 | 航空写真、昔の航空写真 |
| 土地の区画 | 登記所備付地図（14条1項地図・公図）のデータ、自治体の地番図 |
| まちの計画 | 用途地域などの都市計画 |
| 災害の情報 | ハザードマップ（浸水・土砂災害） |

たとえば、公図のデータと航空写真を重ねると、「この土地は今、どんな使われ方をしているか」がひと目でわかります。

## 無料（または基本無料）で使えるGISの例

| 名前 | できること |
| --- | --- |
| 地理院地図（国土地理院） | 地形図・航空写真・昔の写真の切り替え、標高や断面の確認 |
| open-hinata3（個人が開発。一部の機能は有料） | 登記所備付地図のデータや自治体の地番図を、写真や地形図と重ねて表示 |
| [地図ポスト](https://chizupost.com/)（無料のWebGIS） | 全国の公図・地番図を一筆ごとに検索。法務省の地図データ・市町村の地番図・過去の航空写真・基準点などを重ねて表示し、SIMAやDXFなどで書き出せる |
| QGIS（無料のソフト） | パソコンに入れて使う本格的なGIS。データの読み込みや分析ができる |

くわしくは、このサイトの[リンク集](/links/)でも紹介しています。

## 気をつけたいこと

- 公図のデータは、もともとの図面の精度が低いため、写真と重ねると**位置がずれて見える**ことがあります。
- GISで見た位置は、境目の位置を決めるものではありません。境目を確かめたいときは、土地家屋調査士に相談しましょう。
