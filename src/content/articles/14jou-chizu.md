## 条文の整理

| 条文 | 書かれていること（条文のとおり） |
| --- | --- |
| 14条1項 | 登記所には、地図及び建物所在図を備え付けるものとする。 |
| 14条2項 | 前項の地図は、一筆又は二筆以上の土地ごとに作成し、各土地の区画を明確にし、地番を表示するものとする。 |
| 14条4項 | 第一項の規定にかかわらず、登記所には、同項の規定により地図が備え付けられるまでの間、これに代えて、地図に準ずる図面を備え付けることができる。 |
| 14条5項 | 前項の地図に準ずる図面は、一筆又は二筆以上の土地ごとに土地の位置、形状及び地番を表示するものとする。 |

1項の「地図」を実務では**14条1項地図**、4項の図面を**地図に準ずる図面**と呼び分けます。

## 2つのちがい

| | 14条1項地図 | 地図に準ずる図面（14条4項。公図など） |
| --- | --- | --- |
| 根拠 | 14条1項 | 14条4項 |
| おもな元になった図 | 地籍調査の地籍図、法務局が作った地図など | 明治時代の旧土地台帳附属地図など |
| 作り方 | 精度の高い測量に基づく | 測量の精度が低いものが多い |
| 表示するもの | 各土地の区画・地番（2項） | 土地の位置・形状・地番（5項）。ただし形や長さはおおよそのことが多い |
| 現地に境目を復元できるか | できる可能性が高い（座標などから。ただし絶対ではない） | 原則としてむずかしい |

## 実務でのポイント

- まず、取得した図面が上の表のどちらかを確かめます。登記事項証明書や図面の欄外の記載でわかります。
- 公図の長さや面積をそのまま現地に当てはめると、ずれることがあります。地積測量図や現地の境界標とあわせて見ましょう。

条文の正確な文言は、必ず出典の法令原文で確認してください。
