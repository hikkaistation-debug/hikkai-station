## ポイント

- **2025年（令和7年）4月1日**に、電子基準点・三角点・水準点などの標高の値が、衛星測位を基盤とする「測地成果2024」に改定されました。
- **緯度・経度の値は「測地成果2011」から変わっていません。**
- 高さの情報を使う測量では、改定の前後の値がまざらないように注意が必要です。

## 何が変わったの？

| 項目 | 内容 |
| --- | --- |
| 標高の体系 | 衛星測位を基盤とする標高の体系に移行 |
| ジオイド・モデル | 「ジオイド2024日本とその周辺」に変更（2025年4月1日以降の測量で使用） |
| 標高成果の元期（基準の時点） | 2024年（令和6年）6月1日 |
| 基準点成果表の成果値の定義 | 「測地成果2011」から「測地成果2024」に変更 |
| 公共測量 | 「GNSS標高測量」を導入。GNSS測量機による3級水準測量の制限を一部緩和 |
| 離島 | 基準面補正量を導入 |

ジオイドとは、高さの基準になる面のことです。人工衛星で求めた高さ（楕円体高）からジオイドの高さを引くと、標高が求められます。

## どれくらい変わったの？

国土地理院が示している最大の改定量です。

| 種類 | プラス方向 | マイナス方向 |
| --- | --- | --- |
| 三角点 | 宮城県牡鹿半島で +57cm | 北海道知床半島で −67cm |
| 水準点 | 宮城県牡鹿半島で +23cm | 北海道別海町で −40cm |

## 測量の実務で気をつけること

国土地理院は、次の点に注意を呼びかけています。

| 場面 | 注意点 |
| --- | --- |
| 電子基準点の補正情報を使うネットワーク型RTK-GNSSなど | 改定の前後で高さの情報にずれが生じる可能性がある。補正情報を確かめ、前後の高さがまざらないようにする |
| 古いジオイド・モデルしか使えないソフト | 標高を補正する方法が示されている（公共測量を除く） |
| 公共測量 | 「ジオイド2024日本とその周辺」を使う |

## 登記や筆界との関係は？

今回の改定で変わったのは標高で、緯度・経度の値は変わっていません。国土地理院の案内は測量の基準についてのもので、登記や筆界の扱いにはふれていません。

土地の境目の調査や測量のことは、**土地家屋調査士**にご相談ください。くわしい内容は、出典の国土地理院のページで確認してください。このサイトでは、個別のご相談はお受けしていません。
