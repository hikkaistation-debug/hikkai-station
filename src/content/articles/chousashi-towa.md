## 土地家屋調査士とは

土地家屋調査士は、土地や建物が「どこに・どんな形で・どれだけの広さで」あるかを調査・測量して、法務局の登記に正しく反映させる**国家資格者**です。土地家屋調査士法という法律で決められています。

家を新しく建てたとき、土地を分けたいとき、お隣との境目がはっきりしないときに頼る専門家、と覚えておくとわかりやすいです。

## 登記簿の「表題部」を担当

不動産の登記簿は、大きく2つの部分に分かれています。

- **表題部（ひょうだいぶ）**：土地なら場所・地番・地目（土地の使い道）・面積、建物なら場所・種類・構造・床面積など、**不動産そのものの姿**を書く部分です。ここに書く登記を**表示に関する登記**といい、**土地家屋調査士**が担当します。
- **権利部（けんりぶ）**：持ち主はだれか、抵当権（ローンの担保）が付いているかなど、**権利**を書く部分です。主に**司法書士**が担当します。

表示に関する登記の多くは、持ち主に**申請する義務**があります。たとえば建物を新しく建てたときの「建物表題登記」は、建ててから1か月以内に申請することになっています（不動産登記法）。

## おもな仕事

1. **調べる**：法務局の登記簿・公図・地積測量図や、市町村の資料、昔の境界標などを集めて、現地のようすと照らし合わせます。
2. **測る**：測量の機械で土地や建物を測り、図面を作ります。
3. **境目を確かめる（立ち会い）**：お隣の持ち主や、道路を管理する役所の人に立ち会ってもらい、境目を確認して境界標（杭やプレート）を入れます。
4. **登記を申請する**：持ち主に代わって、法務局に表題登記・分筆登記・地目変更登記・滅失登記などを申請します。
5. **筆界特定の手続きを手伝う**：お隣と境目の話がまとまらないとき、法務局に**筆界**（登記で決まった公的な境目）を示してもらう「筆界特定制度」の申請を代わりに行います。
6. **境界の争いを話し合いで解決する手伝い**：法務大臣の認定を受けた土地家屋調査士（ADR認定土地家屋調査士）は、弁護士と一緒に、裁判をしない話し合いの手続き（ADR）で代理人になれます。

筆界と「所有権の境」のちがいは、[「筆界」と「所有権の境」はちがうもの？](/articles/hikkai-to-shoyukenkai/)で説明しています。

## 似ている資格とのちがい

| 資格 | 得意なこと | 測量 | 登記の申請 |
| --- | --- | --- | --- |
| 土地家屋調査士 | 土地・建物の場所・形・広さ・境目 | する（登記のため） | 表示に関する登記 |
| 司法書士 | 売買・相続・抵当権などの権利 | しない | 権利に関する登記 |
| 測量士 | 国や市町村の地図づくり・公共工事の測量 | する（公共測量） | しない |
| 行政書士 | 役所への許可の申請（農地転用の許可など） | しない | しない |

たとえば家を建てて住宅ローンを組むときは、まず土地家屋調査士が「建物表題登記」で建物を登記し、そのあと司法書士が持ち主やローンの登記をする、という順番になります。

## こんなときに頼みます

| こんなとき | おもな手続き |
| --- | --- |
| 家を新しく建てた | 建物表題登記 |
| 建物を取り壊した | 建物滅失登記 |
| 増築した・使い道を変えた | 建物表題変更登記 |
| 土地を売る前に境目をはっきりさせたい | 境界確定測量（立ち会い・境界標の設置） |
| 土地を分けたい（相続・一部を売るなど） | 測量＋分筆登記 |
| 畑を宅地にした | 地目変更登記 |
| お隣と境目の位置について話がまとまらない | 筆界特定制度・境界ADR |

費用は事務所や土地の条件（広さ、お隣の数、資料の残り具合、道路との境目があるか）で大きく変わります。見積もりをとって確かめましょう。

## 資格のとり方

土地家屋調査士になるには、法務省の**土地家屋調査士試験**に合格して、日本土地家屋調査士会連合会に登録するのが一般的です。受験資格（学歴や年齢の条件）はありません。

試験の流れや、測量士補などの資格で筆記の午前の部が免除されるしくみは、[土地家屋調査士試験のしくみ](/articles/shiken-shikumi/)で紹介しています。

## 困ったときは

- **境目を調べたい・測量したい・土地を分けたい・建物の登記をしたい** → 土地家屋調査士に相談しましょう。各地の土地家屋調査士会のホームページで、会員をさがせます。
- **相続や売買で持ち主の名義を変えたい** → 司法書士に相談しましょう。
- **境目のことで争いになっている** → 弁護士に相談しましょう。
- **手続きの流れを知りたい** → 法務局でも案内しています。
