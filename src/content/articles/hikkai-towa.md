## ひとことで言うと

**筆界（ひっかい）**は、**登記された1つの土地と、そのお隣の土地との境目**のことです。

土地は登記の上で「**筆（ふで・ひつ）**」という単位で数えます。1つの土地＝**1筆（いっぴつ）**で、1筆ごとに「〇番」という**地番（ちばん）**が付いています（不動産登記法 第35条）。この**筆と筆の境目**なので「筆界」とよびます。

## 法律ではどう決まっている？

筆界の意味は、不動産登記法 **第123条第1号**に書かれています。かみくだくと、次のとおりです。

- 登記された1筆の土地と、隣の土地とのあいだで
- その土地が**登記されたとき**に、境になるとされた
- **2つ以上の点**と、**その点を結ぶ直線**

## 筆界の大きなポイントは3つ

| ポイント | どういうこと？ |
| --- | --- |
| **1. 登記されたときに決まる** | 点の位置は、その土地が登記されたときに決まっています。いまの塀やフェンスの位置で決まるわけではありません。 |
| **2. 話し合いでは動かせない** | お隣どうしで「ここを境にしよう」と決めても、筆界そのものは変わりません（[最高裁 昭和31年12月28日判決](/hanrei/s311228/)）。 |
| **3. 変わるのは決められた手続きのときだけ** | 土地を分ける**分筆**や、土地区画整理の**換地処分**などで新しい筆界ができ、土地をまとめる**合筆**でそのあいだの筆界がなくなります（くわしくは下の「筆界はいつできたの？」）。 |

「どこまでがだれの持ち物か」という**所有権の境**は、売買や約束で変わることがあります。筆界とのちがいは「[「筆界」と「所有権の境」はちがうもの？](/articles/hikkai-to-shoyukenkai/)」でくわしく説明しています。

## 筆界はいつできたの？

| 筆界のでき方 | どんな筆界？ |
| --- | --- |
| **はじめて登記されたとき** | 多くの土地は、明治時代に土地を1筆ずつ調べて台帳や図面を作ったころまでさかのぼると言われています。とても古い筆界です。 |
| **分筆の登記をしたとき** | 1つの土地を分けたときに、あいだに新しくできる筆界です。測量をして、地積測量図という図面が法務局に出されます。 |
| **土地区画整理などの換地処分のとき** | 区画整理で道路や区画を作り直すと、新しい区画（換地）が、公告の翌日から元の土地とみなされます（土地区画整理法 第104条第1項）。そのあと施行者が登記を申請・嘱託するので（同法 第107条第2項）、地域の筆界がまとめて新しくなります。 |

古い筆界ほど、当時の図面がおおまかで、現地のどこなのかがわかりにくいことがあります。

### 裁判の判決で決まることも

お隣との筆界がどこか、話がまとまらないときは、**境界確定訴訟**（「筆界確定訴訟」ともよばれます）という裁判で、裁判所に筆界の位置を決めてもらうことができます。判決が確定すると、その線が筆界として扱われます。法務局の筆界特定とくいちがうときは、筆界特定のほうが効力を失います（不動産登記法 第148条）。

判決は、新しい筆界を作るというより、**もともとあるはずの筆界がどこかを決めるもの**と説明されることが多いです。

## 筆界の「手がかり」になるもの

筆界は目に見える線ではないので、いろいろな資料や目印を照らし合わせて、現地での位置をさがします。

| 手がかり | どんなもの？ | くわしい記事 |
| --- | --- | --- |
| 境界標（きょうかいひょう） | 境目の点に入っているコンクリート杭・金属プレートなどの目印 | [境界標の種類](/articles/kyokaihyo-shurui/) |
| 地積測量図 | 分筆などのときに法務局に出された、土地の形と長さの図面 | [地積測量図とは？](/articles/chiseki-sokuryozu/) |
| 地図・公図 | 法務局にある、土地の並び方や形を表した図面 | [14条1項地図](/articles/14jou-chizu/)・[公図の移り変わり](/articles/kouzu-hensen/) |
| 登記記録など | 地番・地目・地積（面積）などが書かれた記録 | [法務局で取れる資料](/articles/houmukyoku-shiryou/) |

法務局の筆界特定でも、こうした資料に加えて、土地の形や広さ、塀・境界標があるかどうか、それが置かれたいきさつなどを**総合的に考える**と決められています（不動産登記法 第143条第1項）。

## 筆界がわからないときは

- **筆界の位置を調べたい・測量したい・境界標を入れたい** → **土地家屋調査士**が専門家です（[土地家屋調査士ってどんな人？](/articles/chousashi-towa/)）。各地の土地家屋調査士会でも、境界の相談窓口を設けています。
- **法務局に筆界の位置を調べてもらいたい** → [筆界特定制度](/articles/hikkai-tokutei-seido/)があります。資料が少ないときなどは、位置ではなく「位置の範囲」で示されることもあります（不動産登記法 第123条第2号）。
- **所有権の範囲で争いになっている** → 弁護士に相談しましょう。
