## 立ち会いとは

お隣が土地を売る・分けるときなどに、境界確定測量を行います。そのとき、隣の土地の持ち主として、現地で境目の位置を一緒に確認するのが「立ち会い」です。ふつうは、お隣が頼んだ土地家屋調査士から連絡が来ます。

## 立ち会うと、こんなよいことも

| よいこと | どういうこと？ |
| --- | --- |
| 自分の土地の境目もはっきりする | お隣との境目が確認され、境界標も入る。測量の費用は、一般的には測量を頼んだ方が出すので、自分で頼むより負担が少ない |
| 大切な資料が手に入る | 署名した境界確認書の写しや測量図は、将来、自分が土地を売る・分ける・相続するときの資料になる |
| もめごとを防げる | 境目をお互いに確かめておくと、あとで「どこまでが自分の土地か」で争いになりにくい |

## 立ち会いは義務？

土地の持ち主には、**自分の土地の境界をはっきりさせるための措置を、適切にとるよう努める**責務があります（土地基本法第6条第2項）。

これは「努めなければならない」という努力義務で、「立ち会いをしなければならない」と書かれているわけではありません。それでも、境目をはっきりさせることは、法律でも持ち主に求められていることです。都合がつかないときは、日にちを相談したり、家族に代わりに来てもらったりしましょう。

## 当日の流れ

1. 土地家屋調査士が、資料と測量の結果から考えた境目の位置を説明する
2. 現地で、境界標や印の位置を一緒に見る
3. 納得できれば、後日（またはその場で）**境界確認書**に署名・押印する
4. 確認した位置に境界標が入る

## 持っていくとよいもの

| もの | 理由 |
| --- | --- |
| 自分の土地の測量図や境界確認書（あれば） | 以前に決めた境目と同じかを確かめられる |
| 権利証・登記事項証明書（あれば） | 地番や面積を確かめられる |
| 印鑑 | 境界確認書に押すことがある |

## 心がまえ

| してよいこと | 気をつけたいこと |
| --- | --- |
| わからない点を質問する | よくわからないまま署名しない |
| 資料を見せてもらう | 「とりあえず」で印を押さない |
| 持ち帰って考える・家族に相談する | 感情的に言い合いにならない |
| 納得できなければ保留する | 境界標を自分で動かさない |

署名した境界確認書は、自分の土地の大切な資料になります。写しをもらって保管しておきましょう。
