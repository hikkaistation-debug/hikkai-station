## ポイント

- 土地や建物の登記簿には、持ち主の住所と氏名が書かれています。
- **2026年（令和8年）4月1日から**、住所や氏名が変わったときは、変更の登記を申請することが義務になりました（不動産登記法76条の5）。
- **かんたん・無料の申出**をしておくと、法務局が変更の登記をしてくれるしくみ（スマート変更登記）もあります。

## いつまでに申請するの？

| 住所・氏名が変わった時期 | 申請の期限 |
| --- | --- |
| 2026年4月1日以降 | 変わった日から**2年以内** |
| 2026年4月1日より前（まだ登記していないもの） | **2028年（令和10年）3月31日まで** |

## 申請しないと、すぐ罰があるの？

正当な理由なく義務に違反した場合、5万円以下の過料（かりょう。行政上のお金の制裁）の対象になることがあります（不動産登記法164条2項）。ただ、いきなり科されるわけではありません。法務省の説明では、次の順番です。

| 順番 | 内容 |
| --- | --- |
| 1 | 登記官が義務違反を把握すると、まず**催告書（申請をうながす書面）**を送る |
| 2 | 期限内に登記や申出がなければ、登記官が裁判所に通知する（正当な理由があると認められたときは通知しない） |
| 3 | 裁判所が判断し、過料を決める |

法務省は「正当な理由」の例として、重い病気、DV被害などで避難している場合、経済的に困窮している場合などをあげています。このほかの事情も、個別に判断されます。

## 「スマート変更登記」とは

あらかじめ法務局に「検索用情報」（生年月日など）を申し出ておくと、法務局が住民基本台帳ネットワークで住所などの変更を確かめ、代わりに変更の登記をしてくれるしくみです（不動産登記法76条の6）。

| 順番 | 内容 |
| --- | --- |
| 1 | 持ち主が検索用情報を申し出る（無料） |
| 2 | 法務局が住所などの変更を確かめる |
| 3 | 法務局から意思確認の通知が届き、**希望すると回答する** |
| 4 | 法務局が変更の登記をする |

知っておきたい点をまとめます。

| 項目 | 内容 |
| --- | --- |
| 個人が始まる時期 | 2026年（令和8年）12月中旬以降 |
| 令和8年度の対象 | 2026年3月31日までに検索用情報の登録が完了した人。それより後の人は令和9年度以降 |
| 海外に住んでいる人 | 住民基本台帳ネットワークで確かめられないため、対象外（日本に住所を移したあと、申出をし直せば対象） |
| 好きな時期に頼めるか | 個別には頼めない。急ぐときは自分で申請する |
| 法人 | 2026年5月15日から。会社法人等番号が登記されている場合 |

通知が届いたのに回答しないでいると、催告の対象になることがあります。届いたら、早めに回答しましょう。

## どこに相談すればいい？

住所や氏名の変更の登記は、持ち主に関する「権利に関する登記」です。

- **申請を任せたい** → **司法書士**
- **自分で申請したいので、進め方を知りたい** → 不動産がある場所を担当する**法務局**

登記簿の見方は「[登記事項証明書の見方](/articles/touki-jikou-shomeisho-mikata/)」で、相続があったときの登記は「[相続登記の申請が義務になりました](/articles/souzoku-touki-gimuka/)」で紹介しています。
