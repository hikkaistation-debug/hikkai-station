## 学び方は大きく3つ

| 学び方 | 向いている人 | 気をつけたいこと |
| --- | --- | --- |
| 通学（教室で受講） | 決まった時間に学ぶほうが続く人、講師に直接質問したい人 | 校舎が近くにあるか。費用は高めになりやすい |
| 通信講座（動画・テキスト） | 仕事をしながら、自分のペースで学びたい人 | 一人でも計画どおり進められるか |
| 独学（市販の本・過去問） | 費用をおさえたい人、測量や登記の基礎がある人 | 記述式（作図や書面）の書き方を、自分で身につける必要がある |

## 土地家屋調査士の講座がある主な予備校

| 予備校 | 特徴（公式サイトの案内から） |
| --- | --- |
| [東京法経学院](https://www.thg.co.jp/) | 土地家屋調査士・測量士などの法律資格の講座を中心にしている |
| [LEC東京リーガルマインド](https://www.lec-jp.com/chousashi/) | 土地家屋調査士と測量士補の講座がある。お試しのWeb受講の案内もある |
| [アガルートアカデミー](https://www.agaroot.jp/chousashi/) | オンラインの通信講座。土地家屋調査士と測量士補の講座がある |
| [日建学院](https://www.ksknet.co.jp/nikken/guidance/investigation/index.aspx) | 全国に校舎がある。土地家屋調査士の試験対策の講座がある |
| [早稲田法科専門学院](https://waseda-h.co.jp/course-guide/) | 土地家屋調査士の通信講座（ビデオで学ぶコースなど）がある |
| [まいれぼ](https://myrevo-school.com/) | 土地家屋調査士試験専門のオンライン予備校。過去問のゼミ、模擬試験、オンラインのチューターなどがある |

※順番に意味はありません。ここにない学校や講座もあります。

## 比べるときのポイント

| ポイント | 確かめたいこと |
| --- | --- |
| 午前の部の免除 | 測量士補の講座もセットか。免除を使うなら、測量士補の試験（例年5月ごろ）から計画する |
| 記述式の対策 | 作図や書面の添削があるか。何回まで見てもらえるか |
| 教材 | テキストの見やすさ、動画の長さ、スマートフォンで見られるか |
| 質問 | わからないところを質問できるか。回数や方法（メール・教室） |
| 費用 | 総額のほか、教育訓練給付金（国の補助）の対象講座か |
| 体験 | 無料の体験講義・資料請求があるか |

## 独学で始めるなら

- 法務省のサイトで、[過去の試験問題](/articles/shiken-kuwashiku/)をPDFで見られます。まずは1年分を見て、どんな問題が出るかをつかみましょう。
- 試験の流れは[土地家屋調査士試験のしくみ](/articles/shiken-shikumi/)、勉強の計画は[勉強プランナー](/tools/benkyou/)も参考にしてください。
