## 地積測量図とは

土地を分ける（分筆）、面積を直す（地積更正）、新しく土地を登記する（表題登記）といった登記を申請するときに、**必ず添付する図面**です。法務局で、だれでも写しを取れます。

| 役割 | どういうこと？ |
| --- | --- |
| 面積の計算の根拠を示す | 申請書に書いた地積（面積）が、どう計算されたかがわかる |
| 土地の細かい形を示す | 法務局の地図（公図など）では表せない、境目の長さ・角・境界標などを記録する |

## いつから法務局にあるの？

地積測量図は、どの土地にもあるわけではありません。

| 時期 | 地積測量図は？ |
| --- | --- |
| 「一元化」より前（土地台帳の時代） | 申告書に綴じられていただけで、保存期間は10年。今ではほとんど見られない |
| 「一元化」のあと | 分筆などの登記をするとき、地積測量図を出すことが義務になり、登記所に備え付けられるようになった |

**一元化**とは、昭和35年の不動産登記法の改正で、税務署から引き継いだ「土地台帳」と「登記簿」を1つにまとめたことです。一元化が終わった日（指定期日）は**登記所ごとにちがい**、順番に進んで、終わるまでに10年ほどかかりました。

そのため、**指定期日より前に分筆などの登記をしたきりの土地には、地積測量図がありません**。登記事項証明書の表題部で、分筆などの「原因及びその日付」がいつかを見ると、地積測量図がありそうか見当がつきます。指定期日は、土地のある法務局で確かめましょう。

## 書いてあること（今の図面の場合）

| 項目 | 内容 |
| --- | --- |
| 地番・方位・縮尺 | どの土地の図か、向き、縮める割合（原則250分の1） |
| 筆界点の間の距離 | 境目の角と角の長さ |
| 地積と求積の方法 | 面積と、その計算のしかた |
| 境界標 | 境目の角にある杭やプレートの種類 |
| 筆界点の座標値 | 基準になる点から測った位置の数字。境目を復元する手がかり |
| 作成年月日・作成者 | いつ、だれが作ったか |

（不動産登記規則第77条）

## 作られた時期で、中身がちがう

| 作られた時期 | 特徴 | 現地に復元できるか |
| --- | --- | --- |
| 一元化より前 | 面積を出すため、三角形に分けて「底辺×高さ」で計算する（三斜求積）ための図。まわりの長さはほとんど書かれていない | むずかしいことが多い |
| 一元化のあと〜 | 縮尺は原則300分の1（明治の公図が600分の1だったことによる）。机の上で作ったような図面もある | むずかしいことが多い |
| 昭和52年ごろ〜 | 境界標があれば書くことになった。境界標がなければ、近くの動かないもの（建物の角など）との位置関係を書いて**もよい**（任意）とされたので、書いてある図面とない図面がまじる。縮尺は250分の1・500分の1などに | 図面による |
| 平成5年ごろ〜 | 境界標がないときは、近くの動かないものとの位置関係を書くことが**義務**になり、現地で場所を特定しやすくなった | しやすくなった |
| 平成17年（2005年）〜 | 基準点（基本三角点等）から測った**筆界点の座標値**を書く。分筆の残りの土地も、原則として測って面積を出す（それまでは「元の面積−分けた面積」の差し引きでよかった） | しやすい（ただし絶対ではない） |

※時期と内容は、おおまかな目安です。実際には登記所や図面によってちがいます。

使う道具も、時代とともに変わってきました。平板（図板の上で現地の形を描く道具）から、角度を測るトランシット、光で距離を測るトータルステーション、そして人工衛星を使うGNSSへと進んでいます。

## 見るときのポイント

- **作成年月日**をまず確かめる（上の表のどの時期か）
- 図面の距離と、現地の境界標の間の長さが合うかを見る
- 座標値があっても、基準点が動いたり、境界標が工事でなくなったりしていることもある
- 分筆の残りの土地は、平成17年より前なら差し引きで面積を出しているかもしれない（[面積がちがうのはなぜ？「公差」のはなし](/articles/chiseki-kousa/)）

境目を確かめたいときは、地積測量図を手がかりに、土地家屋調査士に調べてもらいましょう。公図との関係は[公図はどこから来たの？](/articles/kouzu-hensen/)で紹介しています。
