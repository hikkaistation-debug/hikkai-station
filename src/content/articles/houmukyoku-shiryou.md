## 取れる資料と、わかること

| 資料 | わかること |
| --- | --- |
| 登記事項証明書 | 土地・建物の所在・面積・持ち主・抵当権など |
| 14条1項地図、または地図に準ずる図面（公図） | 土地の並び方・形・地番 |
| 地積測量図 | 土地の形・境目の長さ・面積・境界標（分筆などをした土地） |
| 建物図面・各階平面図 | 建物の位置と、各階の形・床面積 |
| 閉鎖登記簿・閉鎖された図面 | 昔の登記の内容や、以前の図面 |
| 旧土地台帳 | 登記簿と一元化される前の土地の記録 |
| 所有不動産記録証明書（2026年2月から） | 自分、または亡くなった家族の名義になっている不動産の一覧（全国分） |

## 取り方

| 方法 | 内容 |
| --- | --- |
| 法務局の窓口 | 請求書に地番などを書いて請求する。全国どこの法務局でも取れる資料が多い |
| オンライン請求 | インターネットで請求して、郵送または窓口で受け取る |
| 登記情報提供サービス | インターネットで内容を見られる（有料）。証明書としては使えない |

手数料は1通あたり数百円です（所有不動産記録証明書は、窓口で1通1,600円）。くわしい金額は法務局のホームページで確かめてください。

## 取るときのコツ

- 住所ではなく**地番**で請求します。地番がわからないときは、法務局で問い合わせましょう。
- 公図は、となりの土地も一緒に写る範囲で取ると、並び方がわかりやすくなります。
- 古い資料（閉鎖登記簿・旧土地台帳）は、扱いが法務局ごとにちがうことがあるので、先に問い合わせると安心です。

## 持っている不動産がわからないとき ――「所有不動産記録証明書」

2026年2月2日から、名義人ごとに不動産の一覧を出してもらえるようになりました（不動産登記法第119条の2）。相続のときに、登記の漏れを防ぐのに役立ちます。

| 項目 | 内容 |
| --- | --- |
| 請求できる人 | 名義人本人、または亡くなった名義人の相続人など |
| わかること | その人の名義になっている不動産の所在と不動産番号。なければ「ない」という証明書が出る |
| 請求先 | 全国どこの法務局でも（オンラインも可） |
| 気をつけたいこと | 登記の氏名・住所と、請求するときの氏名・住所が一致しない不動産は出てこない |

引っ越す前の住所のまま登記されていることもあります。どの住所で請求するとよいか、法務局で相談しましょう。くわしくは[法務局の案内（旭川地方法務局）](https://houmukyoku.moj.go.jp/asahikawa/page000001_00531.html)を見てください。

相続登記の期限については、[相続登記の申請が義務になりました](/articles/souzoku-touki-gimuka/)で紹介しています。

それぞれの資料の読み方は、[登記事項証明書の見方](/articles/touki-jikou-shomeisho-mikata/)、[公図の移り変わり](/articles/kouzu-hensen/)、[地積測量図とは？](/articles/chiseki-sokuryozu/)で紹介しています。
