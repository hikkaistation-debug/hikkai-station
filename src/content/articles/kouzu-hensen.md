## 年表で見る公図の移り変わり

| 時期 | できごと |
| --- | --- |
| 明治6年（1873年）〜 | **地租改正**。土地に税（地租）をかけるため、村ごとに土地を調べて図面（字限図など）を作る。測量は住民が行い、精度はまちまち |
| 明治18年〜22年ごろ | **地押調査（じおしちょうさ）**。図面を作り直した地域もある（更正図） |
| 明治22年（1889年） | 土地台帳の制度ができ、図面は**土地台帳附属地図**として税務署などで管理される |
| 昭和25年（1950年） | 土地台帳の事務が、税務署から**登記所（法務局）**へ移る |
| 昭和35年（1960年） | 登記簿と土地台帳を1つにまとめる（一元化）。土地台帳はなくなるが、附属地図は登記所に残り、「公図」と呼ばれるようになる |
| 平成5年（1993年） | 不動産登記法に「地図に準ずる図面」の規定ができる |
| 平成17年（2005年） | 新しい不動産登記法で、14条4項の「地図に準ずる図面」になる |
| 現在 | 地籍調査などで作られた**14条1項地図**への置き換えが進んでいる |

## 公図が現地と合わない理由

- もともと税を決めるための図で、境目の位置を正確に示す目的ではなかった
- 測量の道具や技術が今ほど整っていなかった
- 山林などでは、実際より面積を小さく届けた例もあるといわれます（実際の面積の方が広い「縄伸び」）
- 和紙の図面を書き写す（再製する）うちに、ずれが生じたものもある

## 公図との付き合い方

公図は、**土地の並び方やおおまかな形**を知るにはとても役に立ちます。一方で、長さや面積をそのまま現地に当てはめることはできません。地積測量図や境界標、隣の土地の資料とあわせて読むのが基本です。

14条1項地図と地図に準ずる図面のちがいは、[法務局の「14条1項地図」と「地図に準ずる図面」](/articles/14jou-chizu/)で整理しています。
