## だれと協議する？

| 隣の土地 | おもな管理者（協議の相手） |
| --- | --- |
| 市町村道 | 市町村 |
| 都道府県道 | 都道府県 |
| 国道 | 国（国道事務所）、または都道府県・政令市 |
| 赤道（あかみち）・青道（あおみち）など、地番のない昔の道や水路 | 多くは市町村 |
| 河川 | 河川を管理する国・都道府県・市町村 |

※赤道・青道は、公図で赤や青に塗られていたことからの呼び名です。

## 流れ

1. 管理者の窓口で、道路台帳や過去の境界確定図を調べる
2. 境界確定（境界協議）の申請をする
3. 管理者の担当者と現地で立ち会う（向かいの土地の持ち主などにも声をかけることがある）
4. 協議がまとまると、境界確定図や確定書を受け取る

申請は持ち主本人もできますが、測量や図面が必要になるので、土地家屋調査士に代理で頼むのが一般的です。

## 期間の目安

申請から確定まで、数か月かかることがよくあります。土地を売る・分ける予定があるなら、早めに始めましょう。

自治体によっては、過去の境界確定図をインターネットで公開しているところもあります（例：[久留米市の取り組み](/articles/kurume-kanmin-kyokai-download/)）。
