## ポイント

- **2026年（令和8年）2月2日から**、自分が登記名義人になっている不動産を、全国分まとめて一覧にした「所有不動産記録証明書」を請求できるようになりました（不動産登記法119条の2第1項）。
- 亡くなった人の名義の分は、**相続人などが請求できます**（同条2項）。
- 検索に使う氏名や住所が登記簿と合わない不動産は、**一覧に出ません**。

## だれが、どこで請求できる？

| 項目 | 内容 |
| --- | --- |
| 請求できる人 | 所有権の登記名義人（法人を含む）、その相続人その他の一般承継人 |
| 代理 | できる（委任状などが必要） |
| 請求先 | 全国の法務局・地方法務局（支局・出張所を含む）。書面（郵送も可）またはオンライン |

## 手数料

検索条件1件について、1通あたりの金額です。

| 請求のしかた | 手数料 |
| --- | --- |
| 書面で請求 | 1,600円 |
| オンラインで請求し、郵送で受け取る | 1,500円 |
| オンラインで請求し、窓口で受け取る | 1,470円 |

該当する不動産がなかったときは「該当がない」という証明がされます。この場合も手数料はかかり、返ってきません。

## 必要な書類

| 請求する人 | 主な書類 |
| --- | --- |
| 名義人本人 | 印鑑証明書、または本人確認書類の写し |
| 相続人 | 上に加えて、相続関係がわかるもの（戸籍謄本、法定相続情報一覧図の写しなど） |
| 過去の氏名・住所で探すとき | 上に加えて、それを証明するもの（戸除籍謄本、住民票の写し、戸籍の附票の写しなど） |

## いちばん大事な注意：一覧に出ないもの

登記簿の情報は、登記をしたときのままになっていることがあります。引っ越しのあと住所を変更していない土地は、今の住所で探しても出てきません。

| 例 | 登記簿の住所 | 今の住所で検索 | 昔の住所でも検索 |
| --- | --- | --- | --- |
| 実家の土地 | 今の住所と同じ | 出る | ― |
| 昔買った山林 | 引っ越し前の住所のまま | **出ない** | 出る |

このほか、法務省は次のものが一覧に出ないと案内しています。

- 所有権の登記がされていない不動産（表示に関する登記だけのもの）
- 登記簿がコンピュータ化されていない不動産
- 検索の時点で登記に反映されていない不動産（審査中の申請など）

反対に、同姓同名の別の人の不動産が出ることもあります。固定資産税の通知書や古い権利証とも見くらべましょう。

## 証明書を取ったあとの流れ

| 順番 | すること |
| --- | --- |
| 1 | 所有不動産記録証明書で、名義の不動産の一覧を見る |
| 2 | 気になる土地の[登記事項証明書](/articles/touki-jikou-shomeisho-mikata/)で中身を確かめる |
| 3 | 名義が亡くなった人のままなら、[相続登記](/articles/souzoku-touki-gimuka/)へ |
| 4 | 場所や境目がはっきりしない土地は、現地の確認へ |

## どこに相談すればいい？

- **証明書の取り方を知りたい** → **法務局**
- **相続登記を任せたい** → **司法書士**
- **土地の境目を調べたい・測りたい** → **土地家屋調査士**
- **相続人どうしで話がまとまらない** → **弁護士**

法務局で取れるほかの資料は「[法務局で取れる土地の資料まとめ](/articles/houmukyoku-shiryou/)」で紹介しています。くわしい内容は、出典の法務省のページで確認してください。このサイトでは、個別のご相談はお受けしていません。
