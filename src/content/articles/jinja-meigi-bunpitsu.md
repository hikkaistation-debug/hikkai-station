## まず押さえること

分筆の登記は、表題部所有者か所有権の登記名義人でなければ申請できません（不動産登記法39条1項）。登記簿の甲区が「村社○○神社」「無格社○○社」のような昔の名義のままでも、所有権の移転の登記をしなくても分筆はできます。そのかわり、次の2つを書類で示す必要があります。

1. **登記簿の「○○神社」と、今の宗教法人「○○神社」が同じ法人であること**（同一性）
2. **今の代表役員に、法人を代表して申請する権限があること**（資格）

## 1. 名義の中身を確かめる

- 登記事項証明書（全部事項）で、甲区の名義の書き方と、名義人の住所（字名・旧村名）を見ます。
- 旧土地台帳や閉鎖登記簿も取り、いつからその名義なのかも確かめます。

## 2. 今の宗教法人と同じ法人であることを示す

### 旧宗教法人から今の宗教法人へ（宗教法人法の附則）

今の宗教法人の多くは、昭和20年の宗教法人令による法人（附則では「旧宗教法人」）から移ってきました。宗教法人法は昭和26年（1951年）4月3日の公布の日から施行され、移り方は附則に書かれています。

| 附則 | 書いてあること |
| --- | --- |
| 3項 | 旧宗教法人は、施行後も宗教法人令による法人として存続できる |
| 5項 | 規則を作って所轄庁の認証を受け、設立の登記をすると、宗教法人法による宗教法人（新宗教法人）になる |
| 15項 | 新宗教法人になるには、施行の日から**1年6か月以内**に認証の申請をする |
| 17項 | 期間内に申請しなかったとき、認証を受けられなかったときは、**解散**する |
| 18項 | 新宗教法人の設立の登記をした日に、旧宗教法人は解散し、その**権利義務は新宗教法人が承継**する |
| 19項 | 旧宗教法人の登記用紙は、登記官が職権で**閉鎖**する |

このため、土地の登記簿が昔の名義のままでも、新宗教法人に移っていれば、その土地は今の宗教法人のものとして扱えます（附則18項）。一方で、法人の登記は古い用紙が閉鎖されているので、つながりを示すには**閉鎖登記簿**を取ることになります（附則19項）。附則17項で解散していた場合は、今の宗教法人とはつながらないので、後の「分筆だけでは済まないケース」になります。

### 同一性を示す書類

移った経緯は神社ごとに違うので、次の書類を組み合わせて同一性を示すのが普通です。

| 書類 | 何を示すか |
| --- | --- |
| 宗教法人の登記事項証明書（今のものに旧名称が出ていなければ、閉鎖登記簿謄本も） | 法人の名称・主たる事務所と、その移り変わり |
| 宗教法人規則と、その認証書の写し | 名称・主たる事務所・由来 |
| 所管庁（都道府県の宗教法人担当課）や、包括法人（神社本庁など）が出す証明 | 旧神社明細帳の記載など、昔の神社とのつながり |

書類でつながらないところは、代表役員の**上申書**（同一の法人である旨を述べ、実印を押して印鑑証明書をつける）で補うことが多いです。どこまで求められるかは法務局ごとに違うので、**事前に相談しておくのが確実**です。

戦後に国有地の譲与を受けた境内地なら、そのときの書類が同一性の裏付けに使えることもあります。

## 3. 名称・住所が今と違うときの扱い

名義人の表示（名称・住所）が今と違っても、分筆のような表示に関する登記では、変更を証する情報をつければ、**名義人の表示を変える登記を先にしなくて済む**扱いが一般的です。

ただし、分筆のあとに売買や寄附で所有権を移すなら、そのときは表示の変更の登記が要ります。先にまとめて済ませておく判断もあります。

## 4. 代表役員の権限を示す

### 誰が申請するか（18条〜20条）

| 条文 | 書いてあること |
| --- | --- |
| 18条1項・2項 | 宗教法人には3人以上の責任役員を置き、そのうち1人を代表役員とする。代表役員は、規則に別段の定めがなければ責任役員の互選で決める |
| 18条3項 | 代表役員は、宗教法人を**代表**し、事務を総理する |
| 19条 | 宗教法人の事務は、規則に別段の定めがなければ、責任役員の定数の**過半数**で決める |
| 20条 | 代表役員が欠けてすぐに後任を選べないときや、病気などで3か月以上職務を行えないときは、**代務者**を置き、代務者が代わりに職務を行う |

分筆の申請は、代表役員が法人を代表して行います。委任状と、法人の登記事項証明書（または会社法人等番号）を用意します。代表役員が亡くなったまま後任が決まっていないときは、代務者が申請することになります。

法人の登記事項証明書には、**代表権を有する者の氏名・住所・資格**が載っています（52条2項6号）。ここで、申請する人に代表権があるかを確かめます。

### 分筆のあとに売るなら（23条・24条）

分筆そのものは財産の処分にあたらないので、23条の公告はふつう要りません。ただし、分筆のあとに**売却などをする**なら、次のきまりがかかります。

| 条文 | 書いてあること |
| --- | --- |
| 23条1号 | 不動産を処分したり担保に供したりするときは、規則で定めるところ（規則に定めがなければ19条の責任役員の過半数）によるほか、その行為の**少なくとも1か月前**に、信者その他の利害関係人に要旨を示して**公告**する |
| 23条ただし書 | 緊急・軽微なときに公告がいらなくなるのは3号〜5号（境内建物の新築や境内地の模様替えなど）だけで、1号の不動産の処分には当てはまらない |
| 24条 | 境内地・境内建物である不動産について、23条に違反した行為は**無効**。ただし、善意の相手方や第三者には無効を主張できない |
| 12条1項8号・52条2項7号 | 財産の処分のきまりは規則に書かれ、境内地などの処分について規則で定めた事項は、法人の登記にも載る |

規則によっては、包括法人（神社本庁など）の承認も要ります。規則と法人の登記事項証明書で、処分にどんな手続が要るかを先に確かめておきます。

## 5. 境界の確認

分筆では、隣の土地との筆界も確かめます。筆界確認書の当事者も、2で確かめた宗教法人の代表役員です。

## 分筆だけでは済まないケース

| こんなとき | どうなるか |
| --- | --- |
| 神社名義でも、実際は氏子や部落（集落）の共有財産だった | 認可地縁団体による手続など、まったく別の整理になることがある。経緯の聞き取りが大事 |
| 今の宗教法人につながらない（期間内に移らず解散していた〔附則17項〕、法人格のない神社になっている） | 清算人の選任などが必要になる。まず司法書士・弁護士と、どう整理するかを決める |

## どこに相談すればいい？

- **分筆の登記・境界の確認** → **土地家屋調査士**
- **所有権の移転や、名義人の表示の変更の登記** → **司法書士**
- **必要な書類の範囲** → 土地がある場所を担当する**法務局**

分筆の全体の流れは「[分筆登記とは？](/articles/bunpitsu-touki/)」で紹介しています。

宗教法人の代表や財産の処分のきまりは、出典の宗教法人法で確認してください。このサイトでは、個別のご相談はお受けしていません。
